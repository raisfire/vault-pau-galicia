PREGUNTA 3. (2 PUNTOS)  
3.1. Escoja cinco adjetivos del texto y proponga un sinónimo para cada uno de ellos; a continuación, 
escoja otros cinco (pueden coincidir o no con los anteriores) y proponga un antónimo para cada 
uno. (1 punto)  
3.2. Muestre, con ejemplos que proporcionen un contexto suficiente, la diferencia de uso entre las 
siguiente parejas de términos: haya / halla; desecho / deshecho; graba / grava; abría / habría; hora / 
ora. (1 punto)
