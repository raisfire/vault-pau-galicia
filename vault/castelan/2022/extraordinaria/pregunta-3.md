PREGUNTA 3. (2 PUNTOS)  
3.1. Busque en el texto un sinónimo para cada una de las siguientes palabras: individuo, 
consecuencia, incremento, costumbres, determinante. A continuación, escoja cinco adjetivos 
del texto y proponga un antónimo para cada uno de ellos. (1 punto) 
3.2.  Indique qué relación existe entre las siguientes parejas o grupos de palabras: rico / pobre; flor 
/ lirio; batalla / lucha; lubina / sardina / lenguado; vaca / baca. (1 punto)
